Install or update on Unraid from the terminal:

```bash
curl -fsSL https://github.com/jcarrnah/clippy-music/releases/latest/download/install.sh | bash
```

Before publishing, this release was installed on a Linux test machine with real Lidarr, slskd and
Vidarr containers. That test confirmed the profiles, the tags and the sync. It didn't cover Unraid
itself, real downloads, Soulseek logins or the Tubifarry plugin.

See the [README](https://github.com/jcarrnah/clippy-music#after-installing) for what to do next.
